# PrenotaZen

**PrenotaZen** è il software che aiuta il tuo ristorante a ricevere e gestire le prenotazioni online.

Ogni ristorante ha:
- una **pagina pubblica di prenotazione** che i clienti usano per richiedere un tavolo, scegliere data, orario e numero di persone;
- un **menù digitale via QR**, che i clienti consultano dal telefono inquadrando il codice al tavolo;
- una **dashboard di gestione** privata, dove gestisci le prenotazioni in arrivo, gli orari di apertura e il menù.

## Privacy

Il trattamento dei dati personali dei clienti è descritto nella pagina **Privacy** raggiungibile dall'app all'indirizzo `/privacy`.
